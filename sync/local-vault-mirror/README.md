# 本地资料库镜像

`mirror-to-vault.mjs` 将部署者指定的飞书 Drive 文件夹单向同步到本地目录，供检索、备份或其他本地工具使用。云端是权威来源；本地修改不会写回飞书。

## 配置

通过命令行参数或环境变量提供源文件夹、目标目录和飞书凭据。不要在脚本、LaunchAgent 或仓库文件中写入真实 token、个人目录或组织名称。

建议为不同产物配置独立子目录，例如源纪要、行业与市场观点 Markdown、行业与市场观点 JSON、标的观点 Markdown 和标的观点 JSON。

## 安全行为

- 只有完整拉取成功后才传播云端删除。
- 源目录缺失、同名歧义或下载失败时停止，不清空本地目录。
- 临时文件通过原子替换提交，避免中断时留下半写入文件。
- 正式启用前使用临时目录进行 dry-run 和删除传播测试。

## 测试
