# 结构化数据链接字段规范

结构化观点链路应使用职责清晰且不重复的链接字段。

| 字段角色 | 作用 |
|---|---|
| 源纪要链接 | 指向已经审核的会议纪要归档 |
| 待审核 Markdown 链接 | 指向当前可编辑的结构化观点 |
| 审核前基线链接 | 指向首次进入审核时的不可变副本 |
| 审核后归档链接 | 指向审核通过后的正式 Markdown |
| 正式 JSON 链接 | 指向从审核后 Markdown 生成的正式 JSON |

字段的实际名称和 field ID 由部署者的 Base 契约提供。迁移时应先核对读写方，再删除重复字段；旧 Workflow 必须停用或更新，避免继续引用已删除字段。
