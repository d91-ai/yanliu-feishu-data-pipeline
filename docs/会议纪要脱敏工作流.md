# 会议纪要脱敏工作流

本文说明如何在会议研究数据管线中生成、审核并归档脱敏版 Markdown，不记录任何组织的实施历史或生产数据。

## 处理范围

1. 从已审核的源纪要读取 Markdown。
2. 调用脱敏 Skill 生成可人工编辑的待审核版本。
3. 由审核人确认人名、联系方式、内部链接及其他敏感信息已移除。
4. 将审核后的版本写入 Drive，并在 Base 中记录版本号、内容哈希和归档链接。

## 安全边界

- 凭据只从本地忽略文件或密钥服务读取。
- Base、table、view、record 和 Drive token 均由部署者配置。
- 脱敏服务不应隐式写入其他知识库或第三方索引。
- 提交前必须重新下载归档文件并校验 SHA-256。

## 部署与验证

使用 `.implementation/feishu-minute-sanitize/` 提供的服务代码，并参考相邻 `.env.example` 创建本地配置。先运行单元测试和 dry-run，再连接测试 Base 完成生成、人工审核、归档和幂等重试验证。
