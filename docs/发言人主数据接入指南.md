# 发言人主数据接入指南

发言人主数据用于将会议中的别名映射为稳定展示名。公开仓库仅提供合成示例，部署者应在本地维护自己的授权数据。

## 文件

- `data/speaker_identity/speaker_master.csv`：已确认的规范身份及别名。
- `data/speaker_identity/speaker_aliases.needs-review.csv`：尚需人工确认的候选关系。

## 使用原则

1. 只在证据充分且经过人工确认后合并身份。
2. “主持人”“老师”“发言人1”等泛称不得跨会议自动归并。
3. 原始发言人和规范发言人应同时保留，便于追溯。
4. 真实名单应放在部署者控制的私有目录，并通过配置挂载。
5. 更新名单后运行冲突、唯一性和端到端回归测试。
