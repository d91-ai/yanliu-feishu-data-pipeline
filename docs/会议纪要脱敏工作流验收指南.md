# 会议纪要脱敏工作流验收指南

本清单用于部署者在自己的飞书环境中验收脱敏分支，不包含既往生产验收结果。

## 配置检查

- 自建应用仅获得必要的 Base 与 Drive 权限。
- `.env` 未被 Git 跟踪，示例配置不含真实值。
- Base、table、view、字段与文件夹标识均来自部署环境。
- 脱敏 Skill 版本和入口能够通过 doctor 检查。

## 功能检查

- 已审核源纪要可以生成待审核脱敏 Markdown。
- 疑似敏感段落会被标记，审核人可以直接修改。
- 审核前基线和审核后归档均保留版本号与 SHA-256。
- 重复任务保持幂等，过期任务不会覆盖新版本。
- 未通过审核、哈希不一致或字段缺失时流程应失败关闭。

## 交付门禁

完成单元测试、合成端到端测试和测试 Base 验收后，方可启用正式 Workflow。真实凭据、日志、业务文件和资源标识不得提交到公开仓库。
