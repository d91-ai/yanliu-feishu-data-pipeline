# 发言人主数据

本目录只提供合成示例，用于验证 `presenter` 与 `presenter_normalized` 的映射能力，不包含任何真实会议参与者。

- `speaker_master.csv`：已经确认、允许自动匹配的示例身份。
- `speaker_aliases.needs-review.csv`：存在泛称、冲突或证据不足的示例候选。

运行时仅加载 `status=confirmed` 的记录，并对规范名和别名进行 Unicode NFKC、首尾空白及英文大小写归一化后的精确唯一匹配。未命中或冲突时保留原始发言人，不得猜测身份。

部署者如需使用真实发言人名单，应将其保存在受控的私有目录，通过配置或只读挂载提供给服务，并确保该目录被 Git 忽略。真实姓名、别名、会议系列和证据路径不得提交到公开仓库。
